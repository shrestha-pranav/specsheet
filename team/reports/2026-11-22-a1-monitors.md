# A1 report: monitors (2026-11-22)

Deliverables: research/monitors/spec-profile.yaml (101 specs, 12 groups, validates against
schemas/category-profile.schema.json, 0 errors), research/monitors/notes.md.

## Decisions
- Identity levels family > model > revision > package. Primary key = model number WITH region suffix (LG -B,
  Samsung XZA, HP #ABA) plus optional hw revision. Panel vendor/part/generation placed at revision level because
  the same model number can ship different panels; they are variant_axes, not model-defining.
- 25 core specs: native refresh vs OC, response basis (GtG/MPRT/fast-mode) separate from value, VESA DisplayHDR
  tier as a closed enum (HDR10/"HDR400" kept only as marketing label), local-dimming type + zones, DCI-P3 with
  gamut basis, bit depth (FRC), PWM, per-port video list (version, bandwidth, max Hz, DSC), USB-C PD W, KVM,
  dead-pixel policy, panel tech/vendor.
- Measured specs (GtG, input lag, HDR window peaks, sustained) are conditioned claims (overdrive, refresh,
  hdr_window_pct) from RTINGS/TFTCentral; the profile does not assume manufacturers publish them.
- Units: US display (in, lb); canonical nit, Hz, W, mm.

## Evidence gathered
- Verified: DisplayHDR tier table (displayhdr.org), Dell U3224KB datasheet (panel IPS Black, 450 typ nit, 5 ms
  Fast-mode GtG, 140 W EPR PD, KVM, VESA 100, Premium Panel Exchange, HDR 600).
- LG 27GR95QE-B via UK/CA mirrors (marketed 27 vs 26.5 viewable, 0.03 ms GtG, 200 nit/1000 nit HDR, DP1.4 + 2 HDMI 2.1).
- Not verified: Samsung/LG US spec tables (404 / JS), RTINGS pages (JS), other brands. See notes.md.
