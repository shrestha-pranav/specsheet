# A2 laptops discovery report, 2026-11-22

## Decisions / findings
- Lenovo PSREF is the jackpot: SPA over an open JSON API (found in the JS bundle). Anonymous JWT via POST
  /api/home/auth/issue (needs Origin+Referer headers; 403 without). robots.txt 404, no CAPTCHA. Catalogue tree needs no auth.
- ShowModel returns every MTM of a product (platform) with 55 columns (CPU, RAM, storage, display, ports, battery, weight,
  warranty, EAN/UPC, Region, Machine Type, announce date). Only page 1 carries `total` and `cols`.
- Adapter built and run: crawler/adapters/lenovo_psref.py (stdlib, <=1 req/s, resumable).
  Catalogue: 1592 products, 917 laptops (282 not withdrawn). Sample: 12 Yoga products -> 4696 MTMs
  (49 US-suffix, 12 `US`-region ones per product avg ~4), 188 requests, ~4 min. raw/lenovo-psref/ (gitignored).
  Full active-laptop run estimate: ~282 products, ~15k MTMs, ~1.2k requests (~25 min).
- Only ~1% of MTMs are US; filter by suffix `US` / Country "USA" / Region NA, keep others as aliases of same platform.
