# A2 report: consumer SSDs (US), 2026-11-23

## Decisions / open questions first
- **Samsung consumer storage is on samsung.com/us, not semiconductor.samsung.com** (that site is OEM/datacenter only; consumer URLs 301). WD_BLACK/Blue/
  Green/Red/My Passport SSDs now live on **sandisk.com** (westerndigital.com products-sitemap has no SSDs). So WD+SanDisk = one source.
- **Blocked, stopped, no workaround**: Crucial (F5 "Request Rejected" on every path incl. robots), Kingston (403/Cloudflare on sitemap + /en/ssd),
  ADATA/XPG (403 incl. robots). Lexar/Sabrent not probed deep (SPA shell / 301). Datasheet PDFs are the only access path for the blocked three.
- Importer contract mismatch for A3: profile says configuration key scheme `mfr_part`; `do_generic` reads configuration-level `mfr_sku`. Adapters emit
  `mfr_sku` (key, with `parent`) + `mfr_part` (alias, same value). Say if you want the importer or the profile to move.
- WD `mfr_model` = product-line slug (no stable stem across Model Numbers); Samsung = part stem (MZ-V9P); TEAMGROUP = P/N stem (TM8FPP). Model-level
  grouping across heatsink/colour variants relies on `stem_links`; review before trusting.
- Revision data is NOT in any official page (WD/TEAMGROUP print no controller/NAND; Samsung "in-house"/V-NAND text): 31 of 55 Samsung SKUs state
  controller or NAND, 1 WD line, 0 TEAMGROUP. Revision children need review/teardown sources (ToS check from A1 still open). 0 revisions emitted.
- Did NOT run import.py/publish (not mine); registry.iter_observations reparse verified for all three.

## Findings
- Samsung page/API defects are real data: 990 PRO 2TB heatsink `GW` row says 1TB capacity; one Controller cell holds the DRAM string (guarded);
  sitemap slug 1tb vs SKU 2T0B; 990 PRO 1/2TB say "3-bit MLC", 4TB says "TLC" (NAND wording changes per capacity).
- TBW on Samsung pages for only 5 SKUs; the rest is in datasheet PDFs (A1 fetched 990 PRO one) -> candidate PDF adapter.
- Per-capacity variation is large (Z44A5 512GB write 2,500 vs 4,500 MB/s; 990 PRO DRAM 1/2/4 GB): claims live on configuration, never model.
- WD `-00BCA0` vs `-00CDD0` suffix on one Model Number (SN850X 8TB), SDSSDE61 under 12 suffixes: candidate package/revision signal only.
