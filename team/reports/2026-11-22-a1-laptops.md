# A1 laptops report (2026-11-22)
Outputs: research/laptops/spec-profile.yaml (78 specs, tiered), research/laptops/notes.md.

## Decisions
- Identity levels: family > platform variant (folded into model) > configuration > package. Key = manufacturer part number (Lenovo MTM, HP SKU+#ABA, Dell orderable SKU, Apple model+BTO tuple), plus region.
- Specs vary at: family (chassis, ports, battery, platform), model/platform (CPU, memory type, PCIe gen, Wi-Fi chip, weight), configuration (RAM, SSD, panel, touch, WWAN, webcam, fingerprint, OS, color), package (charger, warranty, region).
- Core tier (~25): MPN, CPU, GPU+TGP, RAM size/type/soldered/max, SSD size/slots, panel res/Hz/type/nits/gamut/touch, USB-C per-port capability, TB/USB4, Wh, charger W, weight.
- usbc_list is a list of objects (side, protocol, PD in/out, DP) because per-port differences are the biggest hidden item.
- Two evidence classes: official (PSREF, Apple, ASUS, Dell manual) and secondary reviews for unpublished items (PL1/PL2, panel vendor, PD out, TGP); store with provenance.

## Source quality
- Lenovo PSREF PDF: best, fetchable, family-level option lists, per-MTM binding not in PDF. HTML is JS-only.
- Apple: clean server HTML, BTO tuples. ASUS: HTML, options concatenated in one cell. Dell: site 403 to curl.
- HP, Framework, Surface not verified (timeout/404).
