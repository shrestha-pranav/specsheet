# Static dataset v1

`manifest.json` lists categories with schema versions, index shards and facets. Contract: `team/briefs/a4-contract.md`.

Legacy v0 files (`categories.json` fields, `<cat>/products.json`) remain for the chargers pilot and the demo category; `laptops` and `power-strips` also ship a slim `products.json` (column fields only) so the current UI keeps working until A4 switches to `index*.json` + `facets.json`. Every specification has `{value,status,sources,...}`; `status` is known, unknown, conflicted, not_yet_extracted, not_applicable, or not_published. Only known values are established for filtering. Laptops/power strips: the trusted files (`<cat>/index*.json`, `facets.json`, `products/`) contain only claims accepted by a recorded decision (`data/decisions/`: human ledger line or versioned auto-accept policy, id in `manifest.release.policies`) and approved links; unreviewed candidates and proposed links live separately under `preview/<cat>/` (rows flagged `review_scope: preview`, details are deltas over the trusted record). Laptops are US-market only (Lenovo `US` MTMs). The `power-strips-demo` entries are fictional.
