# specsheet

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript with Python dataset generation. The brief delegates stack choice and requires GitHub Pages deployment at `/specsheet/`. No remote services, analytics or third-party font requests.

## Users
Technically literate buyers comparing exact products across brands, including protocol support, electrical limits and configuration identity that marketing obscures.

## Product Purpose
A cross-brand catalogue of structured, source-backed specifications. Success means finding relevant products, comparing two to four, and tracing a specification to its evidence without mistaking missing information for a negative finding.

## Positioning
A reference catalogue, not a shop or deals site. Category schemas drive the interface so the same experience can accommodate chargers, power strips and future non-electronic products.

## Operating Context
Browse categories, narrow a catalogue using factual filters, inspect exact identifiers and source context, and share the current comparison or filtered view by URL.

## Capabilities and Constraints
Home category picker; searchable, sortable, configurable category table; grouped product specifications; source and confidence display; documents and media; comparison; light/dark themes; responsive keyboard-accessible controls. Static dataset distribution is not a dynamic API. Existing charger input files remain unchanged. Demo products must be visibly identified. Architecture section 0 governs identity and absence semantics. No inferred entity merges, inherited electrical claims, or invented evidence.

## Brand Commitments
Name: specsheet. Voice: precise, trustworthy, dense but calm, like a well-made reference work. Unknown is never no. Provenance is first-class.

## Evidence on Hand
Legacy charger JSON in `data/gan-chargers/`, with uneven field-level provenance, unverified identity crosswalks and notes, remains an unreviewed pilot. Published laptops include US configurations and model/family records; published power strips contain real product data. These are unreviewed manufacturer claims, not independent verification. The fictional power-strip demo remains a dataset fixture but is hidden from the catalogue. Media and documents are links when supplied by the published records.

## Product Principles
- Preserve uncertainty and original identifiers.
- Distinguish direct field evidence from record-level context.
- Compare factual attributes rather than marketing rankings.
- Keep category-specific knowledge in schemas and adapters, not interface branches.

## Accessibility & Inclusion
Responsive and keyboard accessible; visible focus, semantic tables, labeled inputs, meaningful status text and sufficient contrast in both themes. Colour never carries state alone.
